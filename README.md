# Monitor de Promoções 5.0 (PWA Funcional • Moedas BRL/USD + Identificador Key/Conta)

Novidades da versão 5.0:
- **Seletor de Moeda (`Livre`, `Somente Real R$`, `Somente Dólar US$`):** Caso não selecione uma moeda específica, a pesquisa permanece livre trazendo ofertas em Real e Dólar. Caso escolha Real (`BRL`) ou Dólar (`USD`), os resultados e alertas são filtrados exclusivamente na moeda escolhida.
- **Identificação Automática (`🔑 Chave (Key)` vs `👤 Conta`):** Cada oferta encontrada e cada alerta disparado exibe claramente se o produto é comercializado como **Chave (Key)** de ativação ou **Conta**.
